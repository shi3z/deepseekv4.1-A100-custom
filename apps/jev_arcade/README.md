# 🎮 Jev Arcade 20 (DeepSeek-V4.1 超高速構造化ジャッジ)

DeepSeek-V4.1 の高速非自己回帰意味空間評価（Jev Mode）と TypeSafe System One モデルを活用した、20種類の体感型ミニゲーム・スイートです。Tailnet を通じて iPad / iPhone Safari やデスクトップブラウザからワンタップで即座に遊ぶことができます。

---

## 🌟 主な特徴

1. **20種類の多彩なゲームジャンル**:
   - 👔 **心理サバイバル**: 『言い訳サバイバル』『AI嘘発見器』『怪しいセールスマン』『AI取調室：カツ丼の壁』『脈アリ判定機』
   - 🧙‍♂️ **RPG・バトル**: 『魔法詠唱バトル』『厨二武器・銘刀鑑定』『キメラ融合実験室』『AIラップ・ローストバトル』
   - 🏯 **大喜利・笑い**: 『AI大喜利道場』『異世界転生面接』『トンデモ教団・布教バトル』
   - ⏳ **極限・推理**: 『1行デスゲーム』『逆アキネーター：秘密当て』『時限爆弾コード解除』
   - ⚖️ **診断・哲学**: 『究極の二択メーカー』『サイコパス診断』『AI天運おみくじ』『激辛覆面料理評論家』『ポーカーフェイス・ブラフ勝負』

2. **iPad & タッチフレンドリーな設計**:
   - 各ゲームに4つの **「⚡ ワンタップで試す」** プリセットボタンを搭載。iPad のソフトウェアキーボードを開かずに即時プレイ可能。
   - 自由入力欄も備え、ユーザー独自のオリジナル呪文や言い訳を試すことも可能。
   - Web Audio API によるシンセサイザー効果音（合否・クリティカルファンファーレ・クリック音）。
   - レスポンシブ＆サイバーパンク・ネオン UI。

3. **デュアルエンジン切替**:
   - **Local 4x A100 DeepSeek-V4.1**: 意味空間ダイレクト査定（レイテンシ ~1.2s、GPUスロットキャッシュ有効時は高速化）。
   - **Official TypeSafe Cloud Jev**: `jev-latest` クラウド API（レイテンシ ~400-500ms）。

---

## 🚀 起動方法

```bash
# 起動スクリプト (デフォルトポート 8888)
./run_jev_arcade.sh
```

- **iPad / Tailnet 接続 URL**: `http://100.126.237.55:8888`
- **ローカル接続 URL**: `http://127.0.0.1:8888`

---

## 📡 API エンドポイント

- `GET /api/games`: 全20ゲームのメタデータ・プリセット・スキーマ定義を返却。
- `GET /api/health`: ローカル DeepSeek サーバー (`:8000`) と TypeSafe API のヘルスチェック。
- `POST /api/play`: プレイヤー入力を評価し、構造化属性・レイテンシ・トークンメトリクスを返却。
